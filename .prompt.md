# 7. Diretrizes de Código

## Organização

- Separar responsabilidades corretamente.
- Controllers não devem conter regras de negócio complexas.
- Services concentram regras de negócio.
- Repository faz acesso ao banco.
- Validações devem ficar separadas.

## Qualidade
- Utilizar nomes claros e objetivos.
- Evitar funções muito grandes.
- Evitar repetição de código.
- Utilizar padronização consistente.
- Comentar apenas regras importantes.

## API
- Seguir padrão REST.
- Utilizar JSON.
- Validar entradas antes de salvar no banco.
- Retornar mensagens claras de erro.

# 8. Regras do Sistema

## Pedidos

Status válidos:

- Na fila
- Em preparo
- Pronto
- Entregue

Regras:

- Cliente e garçom podem criar pedidos.
- Cliente e garçom só podem editar pedidos em “Na fila”.
- Cozinha altera:
  - Na fila → Em preparo
  - Em preparo → Pronto
- Garçom altera:
  -Pronto → Entregue
- Sistema deve registrar tempo em cada status.

## Comandas

- Uma mesa pode possuir múltiplas comandas.
- Cliente acessa mesa via QR Code.
- Cliente pode criar nova comanda.
- Cliente pode renomear apenas sua própria comanda.
- Garçom pode transferir comandas entre mesas.
- Comanda não pode ser excluída com pedidos associados.

## Segurança

- Usuários administrativos precisam de autenticação.
- Utilizar hash para senhas.
- Validar permissões no backend.
- Cliente acessa apenas a mesa vinculada ao QR Code.
- Não expor informações sensíveis.

# 11. O que evitar no MVP

Evitar inicialmente:

- microserviços;
- websocket;
- dashboards complexos;
- arquitetura excessivamente abstrata;
- autenticação complexa para clientes;
- integrações externas desnecessárias;
- otimizações prematuras.

# 12. Diretrizes de UX e Usabilidade

O sistema deve priorizar:

- rapidez;
- simplicidade;
- poucos cliques;
- boa visualização mobile;
- feedback visual claro;
- responsividade.

O cliente deve conseguir:

- acessar via QR Code;
- visualizar cardápio rapidamente;
- fazer pedido em poucos passos;
- acompanhar pedido facilmente.

# 13. Critérios de Segurança

- proteção contra acesso indevido;
- rastreabilidade de ações.
